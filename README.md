# KompOff

Простой одностраничный сайт для магазина и сервиса KompOff.

## Как открыть

Откройте файл `index.html` в браузере Chrome.

## Что внутри

- `index.html` — основная структура сайта
- `styles.css` — чёрно-оранжевая тема
- `script.js` — копирование телефона в буфер обмена

## Публичный доступ

Сайт является статическим и готов к публикации через GitHub Pages или любой другой хостинг.

### GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте в GitHub: `Settings` → `Pages`.
4. Выберите `Deploy from a branch` и `main` / `root`.
5. После публикации получите ссылку вида: `https://your-name.github.io/repository-name/`

## NFC

После публикации сайта через HTTPS можно записать ссылку на NFC-карту.
